# ProTech Academy

The ProTech Academy website is a React single-page application for the academy's courses, admissions, instructors, facilities, and contact information. It includes multilingual content and responsive layouts.

## Development

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

## Production

Create an optimized production build and preview it locally:

```sh
npm run build
npm run preview
```

The PT favicon is maintained in `src/assets/favicon.png`. Main application routes are `/`, `/teachers`, and `/facilities`.
